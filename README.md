# AI Personalization Evaluation Portfolio

A structured collection of evaluations assessing how well AI assistants personalize responses using cross-platform context.

## Purpose

This portfolio demonstrates a systematic approach to evaluating AI personalization quality across three core dimensions: **Grounding**, **Integration**, and **Helpfulness**.

## Evaluation Dimensions

| Dimension | What It Measures | Key Questions |
|-----------|------------------|---------------|
| **Grounding** | Factual accuracy of personalized claims | Does the response accurately reflect data from connected sources? |
| **Integration** | Natural use of personal context | Does the personalization feel seamless or forced? |
| **Helpfulness** | Actionable value for the user | Does the personalization make the response more useful? |

## Scoring Scale

Each dimension is scored 1-5.

| Score | Label |
|-------|-------|
| 5 | Excellent |
| 4 | Good |
| 3 | Acceptable |
| 2 | Below Average |
| 1 | Poor |
